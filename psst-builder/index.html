PSST

사업계획서 & 예비창업패키지 PPT 빌더

아이디어 입력 → PSST 사업계획서 → PPT 편집 → 디자인 프레젠테이션

› › ›
STEP 1

창업 아이디어 입력

아이디어를 입력하시면 PSST 4단계 사업계획서 초안을 자동으로 구성해 드립니다.

예시 불러오기:

각 항목을 클릭하여 내용을 직접 수정할 수 있습니다. 수정 내용은 3단계 PPT에 자동 반영됩니다.
각 슬라이드의 제목과 항목을 직접 수정할 수 있습니다. 수정 내용은 PPT(.pptx)에 그대로 반영됩니다.
STEP 3 · READY

예비창업패키지 발표자료 (총 12슬라이드)

각 슬라이드 항목을 수정한 뒤 4단계: 프레젠테이션 보기를 누르면 디자인이 입혀진 발표 화면으로 확인할 수 있습니다.

디자인 테마:
1 / 12 키보드 좌우 화살표(← / →)로 슬라이드를 넘길 수 있습니다.

AI 생성 엔진 설정 (선택 사항)

API 키가 없어도 내장 PSST 스마트 엔진으로 즉시 사업계획서와 PPT를 생성할 수 있습니다.
Gemini API 키를 입력하면 입력한 아이디어에 맞춘 심층 맞춤형 내용으로 생성됩니다. (키는 브라우저 로컬에만 저장됩니다)
